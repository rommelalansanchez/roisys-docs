🐋 Orca Desktop ADE

Step-by-step Interactive Getting Started Guide

1

Connect Your Git Repository

Before launching AI agents, Orca needs access to your local codebase or a remote repository.

  • Launch the Orca Desktop application on your computer.
  • On the main dashboard, click the "+ Add Repository" button in the left sidebar.
  • Choose "Open Local Folder" to select an existing Git repository on your drive, or select "Clone Remote" to download a repository from GitHub/GitLab.
  • Once loaded, verify that your active branch (e.g., main or develop) is displayed in the bottom-left status bar.
💡 Note: Make sure your project directory contains a valid .git folder. Orca relies on Git to isolate AI changes safely.
2

Create a Task (Isolated Worktree)

Orca uses Git Worktrees to run AI agents in isolated environments so they never mess up your main codebase while working.

  • Click on "New Task" (or press Ctrl+N / Cmd+N).
  • Enter a short descriptive title for what you want the AI to do (e.g., "Add user login form" or "Fix API timeout error").
  • Orca will automatically spin up a dedicated Git Worktree branch in the background.
  • You can create multiple tasks concurrently; each task runs in its own independent workspace without file locks or code bleeding.
💡 Key Advantage: You can keep coding on your main branch while three different AI agents work on three separate tasks simultaneously.
3

Select Model & Instruct Agent

Configure which LLM will execute the code changes and provide detailed instructions.

  • In the top right panel of the task window, select your preferred model from the dropdown (e.g., Claude 3.5 Sonnet, DeepSeek V3, or local models via Ollama/LM Studio).
  • Type your prompt in the instruction panel. Be specific about expected outcomes, file paths, or constraints.
  • Click "Start Agent" or press Enter.
  • Watch the agent inspect files, write terminal commands, and draft code updates in real-time.
💡 Best Practice: Refer directly to relevant files using `@` mentions (e.g., "Check `@src/auth.js` and update error handling") for higher accuracy.
4

Supervise, Interfere & Edit

Unlike standard chat tools, Orca gives you complete control to pause, steer, or manually override the AI mid-process.

  • Terminal & Execution: Inspect terminal output in the built-in terminal pane as the agent executes scripts or tests.
  • Monaco Code Editor: Click on any modified file to open it in the integrated Monaco editor. You can edit code directly alongside the AI.
  • Design Mode / Browser Preview: Switch to the Design View tab to preview web UI changes live.
  • Steer/Pause: Hit "Pause" at any point to stop agent execution, modify files manually, and resume.
💡 Human-in-the-loop: If the AI gets stuck in a loop, click "Interfere", guide it with a quick text correction, and let it resume.
5

Review, Merge & Ship

Once the agent completes the task, review all modifications before integrating them into your main code branch.

  • Click on the "Diff Viewer" tab to inspect green/red line-by-line file changes.
  • Run unit tests directly inside Orca's terminal to confirm everything passes smoothly.
  • If satisfied, click "Merge to Main" to automatically apply the worktree changes back to your target branch.
  • Alternatively, click "Create Pull Request" to push the task branch directly to GitHub for team review.
  • Close or delete the task workspace to clean up the temporary Git worktree.
🚀 Done! Your feature is safely merged. You are ready to start a new task.
