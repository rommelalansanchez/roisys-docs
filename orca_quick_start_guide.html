Orca Quick Start Guide

Agent Development Environment (ADE) Desktop App Overview

Understanding Orca (ADE)

Unlike traditional IDEs designed for a single user writing code, Orca is an Agent Development Environment (ADE). It is built to orchestrate and supervise multiple AI coding agents operating in parallel on your repository.


Worktree Isolation

Every task automatically runs in its own isolated git worktree branch, preventing agents from overwriting each other's code.

Bring Your Own Agent

Works with existing CLI tools like Claude Code, Gemini, Codex, Cursor CLI, and custom agents.

How to Use Orca in 5 Simple Steps

1

Add Your Repository

Open Orca Desktop and point it to your local Git repository folder.

2

Create a Task (Worktree)

Click + to start a task (e.g., fix-auth-bug). Orca automatically creates an isolated Git worktree.

3

Pick an AI Agent

Select which agent to launch in that task's terminal (e.g., Claude Code or Gemini).

4

Inspect & Review

Use split panes to watch agents work, preview changes in the integrated browser, or edit manually in the built-in Monaco editor.

5

Merge or Ship

Review the generated diffs, approve changes, and merge the task back into your main branch or open a PR.

Key Desktop Features

Parallel Tasks

Run multiple tasks simultaneously side by side without branch collision.

Design Mode / Web Preview

Built-in browser tab that lets you click front-end elements to send DOM snippets and screenshots directly to the agent.

Diff Annotation

Highlight code diffs and add inline notes/prompts for your AI agent to refine.

Integrated Terminal & Editor

GPU-accelerated terminal and built-in editor so you can make manual tweaks without leaving the desktop app.
